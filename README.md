# Three Point Shootout
## A game built in Python with Pygame
### Requirements:
[Pygame](https://www.pygame.org)

[SciPy](https://scipy.org)

### How to Play:
Start the game with:
  `$ python main.py`

Once the game has loaded, press "Space" to start the game. After 3 seconds, the game will begin. You have 70 seconds to shoot all basketballs from the 5 different racks, and 2 deep shots.

Shoot the ball by holding down the space bar, release the space bar when the timing bar is in the green to have the best chance at making the shot.

The standard orange balls are worth 1 point, the blue "money balls' are worth 2 points, and the green "deep shot" balls are worth 3 points. Try to score as many points as possible!

When the game is over, press the space bar to try again!
